# v3.0.0 App Store「このバージョンの新機能（What's New）」

App Store Connect の「このバージョンの新機能」欄にそのまま貼り付ける文面。

---

アプリの見た目を全面リニューアルしました。

■ デザイン刷新
・ダークテーマに一新しました
・アプリ全体の配色・文字・アイコンを見直し、ジムの写真がより見やすくなりました
・投稿完了時の演出やボタンの操作感など、細かな手触りを改善しました

■ ホームジムを地図から選べるように
・プロフィール編集のホームジム設定で、地図を見ながらジムを選べるようになりました

■ プロフィール画像のトリミング
・アイコン設定時に、写真の位置や大きさを調整してから設定できるようになりました
・実際に表示されるサイズのプレビューをその場で確認できます

■ その他
・地図画面の表示崩れを改善しました
・細かな不具合を修正しました
