## 説明（4000文字以内）

```
イワノボリタイは、ボルダリングジムを探して、登った日を残すためのアプリです。

■ 全国430のジムを、地図と条件から
・現在地まわりのジムをピンで表示。写真・最低料金・営業中かどうかをその場で確認
・都道府県、種目（ボルダリング／リード／スピード）、最低料金で絞り込み
・ジム詳細では写真・住所・電話・営業時間・料金体系をまとめて確認。気になるジムは「イキタイ」に登録

■ 登った日を、その場で記録
・ジムと日付を選んで、ひと言と写真（最大5枚）を投稿
・マイページには今月の回数・施設数・週ペース、ボルダリング歴、ホームジムを表示
・月ごとの統計レポートで、通ったジムのTOP5と週ペースを自動で振り返り

■ みんなのボル活
・他のクライマーの記録をタイムラインで
・気になる人はお気に入りに追加して追いかける

■ v3.0.0 の主な変更
・夜のボルダリングウォールをイメージしたダークテーマに全面リニューアル
・ホームジムを地図から視覚的に選択
・プロフィール画像のトリミングと、実際に表示されるサイズのプレビュー

ジムの写真は随時募集しています。アプリ内のフォームからお送りください。
```
