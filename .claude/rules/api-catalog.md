# バックエンドAPI一覧の維持ルール（このプロジェクト専用）

バックエンド（Cloud Run / Express + TypeScript）の全APIエンドポイントを、
Google スプレッドシートで一元管理する。**コードが正**であり、この一覧はコードに追従させる。

## 置き場所

- **スプレッドシート**: 「イワノボリタイ_バックエンドAPI一覧」（Google Drive。接続アカウント km.solo.developer@gmail.com 側）
  https://docs.google.com/spreadsheets/d/1Y0hsZFJ9792eFqVpDt3DcWL6zUhZeXE8um5PAWRM1Ko/edit
- タブ構成: **API一覧** / **凡例・更新ルール** / **改訂履歴**

## 更新ルール（必須）

**バックエンドの `backend/src/routes/*.ts`（および `index.ts` 直下のエンドポイント）に
APIを追加・変更・削除したら、必ず同じ作業（PR）の中でこのスプレッドシートも更新する。**

- **追加**: 「API一覧」タブの、そのカテゴリの並びに合わせて行を挿入し、`No.` を1から振り直す
  （コード側のコメント番号とは無関係。連番はスプレッドシート独自で常にきれいに保つ）
- **変更**: 該当行を修正する
- **削除**: 行を削除する（または備考に「廃止YYYY-MM-DD」）。その後 `No.` を振り直す
- いずれの場合も「改訂履歴」タブに1行（日付・変更種別・内容・対応PR/コミット・記入者）を追記する

## 列（API一覧タブ・12列）

No. / カテゴリ / メソッド / パス / 概要 / 認証 / パスパラメータ / クエリ・ボディ /
レスポンス(200) / 主なエラー / 定義場所 / 備考

## 認証区分（コードのミドルウェアと対応）

- **不要**: ミドルウェアなし
- **任意**: `optionalAuthenticate`（未ログイン可・あればユーザーを加味）
- **必須**: `authenticate`（トークン必須。多くは本人のみ＝他人は403）
- **内部(Cloud Tasks)**: `verifyCloudTasksAuth`（Cloud Tasks OIDC想定・現状は簡易チェック=S-2）
