# コード・インフラ編集禁止ルール（現在有効）

- このアプリは**配信済み・大規模・複雑**である。
- **ユーザーが明示的に許可するまで、アプリのコード（lib/, backend/ 等）およびインフラ関連
  （GCP, Firebase, Supabase, Docker, iOS/Android設定, CI等）の編集・実行変更を行わない。**
- 許可されているのは読み取り（調査・分析・報告）と、`.claude/` 配下・`CLAUDE.md`・`.gitignore` 等の
  プロジェクト管理ファイルの整備のみ。
- 調査で見つけた冗長・不要・未使用コードも**削除せず**、`.claude/docs/refactor-candidates.md` に記録するに留める。
- このルールはユーザーが解除を宣言するまで有効。解除されたら本ファイルを更新すること。
