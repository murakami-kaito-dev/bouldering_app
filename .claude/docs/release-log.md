## 【開発版】2.0.0 (build 9) — 2026-09-01 · TestFlight（イワノボリタイ Dev）

- **build 8実機確認で発覚した「再読み込み無反応」の真因を修正**（PR #42に追加）: Riverpod 2.xはエラー状態のAsyncValueに `.value` でアクセスすると例外を再スローする仕様。retryUserLoadIfNeededのガードがこれを踏みloginに到達する前に死んでいた → valueOrNullへ。同型バグ4箇所（user_profile_section=ビルド6/7のマイページグレーの真因、profile_edit_page×3）も統一修正
- **ジム写真の失敗固定化を解消**: 取得失敗を空セットに丸めてProviderが「写真なし」をアプリ再起動までメモ化していた（HOMIE redbrick warehouseで再現・dev APIに写真5枚実在を確認）→ 失敗は例外伝播し30秒後にキャッシュ破棄→再表示で自動再取得

**配信**: TestFlight にアップロード済み（Delivery UUID `c004bf8f-3804-44d8-a88a-5c3f4915fc86`、エラー0）
**状態**: 内部テスター配信（審査提出なし）
