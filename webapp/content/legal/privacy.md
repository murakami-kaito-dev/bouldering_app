## 2. 取得する情報 {#privacy-2}

- **アカウント情報**：Google アカウントまたは Apple ID によるログイン時に発行される利用者 ID（Firebase Authentication の UID）およびログイン方法。<br>認証は Firebase Authentication を通じて行い、当方はパスワードを取得・保管しません。<br>ログインに用いるアカウントの氏名・メールアドレス等は Firebase Authentication 上で管理され、当方のデータベースには、利用者が任意で登録したメールアドレス以外は保存しません。
- **メールアドレス（任意）**：お知らせ等の通知用として、利用者が設定画面から登録するもの。<br>当方のシステムから送信する確認メール内のリンクを開いた時点で登録が完了します。
- **プロフィール情報**：ユーザー名、アイコン画像、自己紹介、性別、生年月日、ボルダリング歴（開始日）、ホームジム・好きなジム等（いずれも任意）
- **投稿・活動情報**：ボル活投稿（施設名・訪問日・コメント・写真等）、イキタイ（行きたいジム）の登録、ブロックした利用者等
- **位置情報**：近くのジム検索等を利用する際、端末（iOS アプリ）またはブラウザ（Web 版）の許可に基づき取得します（任意）。<br>位置情報は検索のために利用し、履歴として保存することはありません。
- **アクセスログ**：IP アドレス、アクセス日時、ブラウザ・端末の種類等
- **Cookie 等（Web 版）**：ログイン状態の保持および広告配信のための Cookie・ブラウザストレージ（詳細は[第6条](#privacy-6)）
- **報告情報**：他の利用者からの報告内容等

## 3. 利用目的 {#privacy-3}

- 認証、アカウント管理、本サービスの提供
- 投稿・画像の表示、共有、検索等のコミュニティ機能の提供
- 地図表示・近くのジム検索等、位置情報を用いた機能の提供
- 不正行為の防止、セキュリティ確保、障害対応
- サービス改善・新機能開発のための統計・分析（統計化・匿名化する場合があります）
- 規約変更や重要なお知らせ等の通知（メールアドレスを登録した利用者にはメールで送信する場合があります）
- 利用規約違反の調査・対応
- 利用者からの報告への対応、不適切コンテンツの削除判断
- Web 版における広告の配信（[第6条](#privacy-6)）

## 4. 公開範囲（重要） {#privacy-4}

- 本サービスは「公開 SNS」です。
- 投稿（テキスト・写真）、プロフィール（ユーザー名・アイコン画像・自己紹介・ボルダリング歴・ホームジム等）、イキタイの登録内容は、原則として一般公開されます。<br>iOS アプリ・Web 版のいずれでもログインしていない閲覧者に表示され、Web 版では検索エンジンにも表示されます。
- 性別・生年月日を登録した場合、プロフィールに性別や年齢として表示されることがあります。
- メールアドレス、位置情報、報告内容、ブロックの設定は公開されません。

<p class="callout">投稿の公開・削除に関するルールは <a href="/terms#terms-4">利用規約第4条</a> をご確認ください。</p>

## 5. 第三者提供・委託 {#privacy-5}

当方は、本サービスの提供のために次の外部サービスを利用し、必要最小限の範囲で情報を預託・処理します。

法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供することはありません。

- **認証**：Firebase Authentication（Google LLC）— Google／Apple ログインの処理
- **データ保存**：Supabase（Supabase Inc.）— アカウント・投稿等のデータベース
- **画像の保存・配信**：Google Cloud Storage（Google LLC）
- **実行基盤**：Google Cloud（Cloud Run 等・Google LLC）— バックエンド API および Web 版のサーバー
- **Web 版の配信**：Firebase Hosting（Google LLC）
- **地図・ジム写真等の表示**：Google Maps Platform／Places API（Google LLC）。<br>ジムの写真の一部は Google から提供されるコンテンツを、提供元の表示とともに掲載します
- **メール送信**：Brevo（旧 Sendinblue）— メールアドレス確認用のメールおよびお知らせ等の送信（メールアドレスを登録した利用者のみ。<br>送信機能の提供開始後に適用）
- **広告配信**：Google AdSense（Google LLC）— Web 版のみ（[第6条](#privacy-6)）

ログインに用いるアカウントの提供元は、各社のプライバシーポリシーに従って情報を取り扱います：[Google プライバシーポリシー](https://policies.google.com/privacy)／[Apple のプライバシーポリシー](https://www.apple.com/jp/legal/privacy/)

## 6. Cookie 等の利用と広告（Web 版） {#privacy-6}

本サービスの Web 版は、次の目的で Cookie およびブラウザのストレージ（localStorage・IndexedDB 等）を利用します。

- **ログイン状態の保持**：Firebase Authentication が、ログインセッションをブラウザのストレージに保存します。
- **広告の配信**：Google AdSense が Cookie を利用します（下記）。
- iOS アプリでは Cookie を利用せず、広告も表示していません。

**第三者配信の広告について**

- 本サービスの Web 版では、第三者配信の広告サービス「Google AdSense」（Google LLC）を利用することがあります。
- Google などの第三者配信事業者は Cookie を使用し、利用者が本サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて広告を配信します。
- Google が広告 Cookie を使用することにより、Google およびそのパートナーは、利用者による本サイトや他のサイトへのアクセス情報に基づく適切な広告を表示できます。
- 利用者は、[Google の広告設定](https://www.google.com/settings/ads)でパーソナライズ広告を無効にできます。<br>また、[www.aboutads.info](https://www.aboutads.info/choices/) や [optout.aboutads.info](https://optout.aboutads.info/)（いずれも英語）で、第三者配信事業者によるパーソナライズ広告向けの Cookie を無効にすることもできます。
- Google による広告 Cookie の使用については、[Google のポリシーと規約「広告」](https://policies.google.com/technologies/ads)をご参照ください。
- Cookie はブラウザの設定で無効化・削除できます。<br>ただし、無効化するとログイン状態の保持など一部の機能が利用できなくなることがあります。
- 現在、アクセス解析ツール（Google アナリティクス等）は導入していません。<br>導入する場合は、本ポリシーを改定してお知らせします。

## 7. 保存期間 {#privacy-7}

- **アカウント・投稿データ**：利用者の削除／退会申請があるまで保存。<br>退会申請後は原則 30 日以内に削除（バックアップ等に一定期間残存する場合あり）。
- **メールアドレスの確認用データ**：確認メール内のリンクの有効期限は原則 24 時間です。
- **サーバーログ**：最大 30 日保存。

<p class="callout">退会の手続きは <a href="/terms#terms-9">利用規約第9条</a> をご確認ください。</p>

## 8. 国外移転 {#privacy-8}

当方が利用する外部サービス（Google、Supabase、Brevo 等）のサーバーは国外（例：米国・EU 等）に設置される場合があり、適用法令に基づき必要な保護措置を講じます。

## 9. セキュリティ {#privacy-9}

TLS による暗号化、アクセス制御、権限管理、監査ログ、脆弱性対策など合理的な安全管理措置を実施します。

ただし、インターネット上の完全な安全性を保証するものではありません。

## 10. 未成年の利用 {#privacy-10}

- 13 歳未満の方は利用できません。
- 13 歳以上の未成年の方は、保護者の同意を得た上でご利用ください。

## 11. 利用者の権利 {#privacy-11}

- 適用法令に基づき、保有個人データの開示・訂正・削除・利用停止、同意撤回等を請求できます。
- 申請窓口：[第1条](#privacy-1)のメールアドレス
- 本人確認のため、追加情報の提示をお願いする場合があります。
- アカウントの削除（退会）は、本サービス内の設定画面からご自身で行えます（[利用規約第9条](/terms#terms-9)）。

## 12. 改定 {#privacy-12}

法令やサービス内容の変更に応じて本ポリシーを改定することがあります。

重要な変更は、本サービス上の表示やお知らせ等で周知します。
